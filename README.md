## Como rodar

Precisa de Java 17+ e Maven.

```bash
cd SEMANA10
mvn verify
```

```bash
cd SEMANA11/exercicios_integracao_springboot
mvn test
```

O relatório de cobertura fica em `target/site/jacoco/index.html` de cada projeto.
